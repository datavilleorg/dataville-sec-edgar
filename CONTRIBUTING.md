# Contributing

Thanks for your interest! Issues and pull requests are welcome.

- **Bugs / ideas:** open an issue with what you ran, what you expected, and what happened.
- **Pull requests:** keep them focused, and describe how you tested the change.
- **Provenance is a feature:** any new output must keep each claim tied to its source (the filing it came from) and keep the form, period and filing link with every figure.
- **Secrets:** never commit an API key. Pass it through an environment variable such as `DATAVILLE_API_KEY`.

Questions about the Dataville API itself: support@dataville.com.
